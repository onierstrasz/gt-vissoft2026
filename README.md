
# README

This repo holds the source code for the VISSOFT 2026 talk and demo.
## Installation

```st
Metacello new
	repository: 'github://onierstrasz/gt-vissoft2026:main/src';
	baseline: 'GtVissoft2026';
	load
```

## Load Lepiter

After installing with Metacello, you will be able to execute

```
#BaselineOfGtVissoft2026 asClass loadLepiter
```
